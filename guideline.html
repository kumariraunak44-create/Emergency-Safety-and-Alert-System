Campus Alert Network – Guidelines

  • Use this system only for real and serious complaints.
  • No personal details are required. You remain anonymous.
  • Give clear details of the problem so authorities can act quickly.
  • Do not misuse the complaint box for jokes or false reports.
  • Emergency issues (violence, harassment, accidents) should be reported immediately.
  • Respect others' privacy while submitting complaints.
  • Use polite and respectful language.
  • Never include sensitive information like phone numbers or addresses.
Note: Your identity is never collected. System fully supports anonymous reporting.
